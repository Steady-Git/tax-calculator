🏠 청약홈 분양정보 조회

한국부동산원 청약홈 공공데이터 API 활용 서비스

⚠️ CORS 안내: 이 HTML 파일을 그냥 더블클릭해서 열면 보안 정책(CORS)으로 인해 API 호출이 차단될 수 있어요.
아래 방법 중 하나를 사용하세요:
  ① VS Code의 Live Server 확장 프로그램으로 열기
  ② 명령 프롬프트에서 python -m http.server 8000 실행 후 → http://localhost:8000 접속
  ③ API가 차단되면 샘플 데이터 보기 버튼을 눌러 미리보기 가능
📌 데이터 출처: 한국부동산원 청약홈 공공데이터포털 (api.odcloud.kr)
일 최대 40,000회 호출 가능 / 데이터 포맷: JSON+XML
